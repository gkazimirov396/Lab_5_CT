# Лабораторна робота №5 з хмарних технологій

## Опис

Даний репозиторій створено для виконання лабораторної роботи №5 з дисципліни «Хмарні технології». У проєкті продемонстровано базову роботу з Git та GitHub: створення репозиторію, робота з комітами, гілками, Pull Request та GitHub Actions.

## Мета роботи

Мета лабораторної роботи:

- ознайомитися з можливостями GitHub;
- навчитися працювати з Git-репозиторіями;
- освоїти роботу з гілками та комітами;
- створити Pull Request;
- налаштувати GitHub Actions;
- опублікувати результати через GitHub Pages.

## Структура проєкту

- `src/app.py` — основний Python-скрипт;
- `README.md` — документація проєкту;
- `.github/workflows/ci.yml` — workflow для GitHub Actions;
- `index.html` — вебсторінка для GitHub Pages.

## Інструкція запуску

Запуск Python-скрипта:

```bash
python src/app.py
```

Очікуваний результат:

```text
Hello, GitHub Cloud Lab!
```
